TAILWIND CSS

Tailwind CSS란?

CSS를 직접 쓰는 대신, 미리 만들어진 클래스를 조합하는 방식.

🎨 일반 CSS

.button { background: #000; color: #fff; padding: 12px 24px; border-radius: 100px; font-weight: 700; }

🎯 Tailwind CSS

<button class=" bg-black text-white px-6 py-3 rounded-full font-bold" > 신청하기 </button>
🔑 바이브코딩에서는 "Tailwind CSS로 스타일링해줘"라고 말하면 AI가 알아서 적용해줍니다.

STRUCTURE

좋은 랜딩페이지의 구조

  1. 히어로 섹션
    한 줄로 핵심 가치를 전달 + CTA(행동 유도) 버튼
  2. 문제 제기
    "이런 불편함 겪고 계시죠?" — 공감을 만드는 섹션
  3. 솔루션 소개
    문제를 해결하는 방법을 3가지 카드 형태로
  4. 신뢰 요소
    후기, 숫자 통계, 기업 로고 등
  5. CTA 반복
    하단에 다시 한번 행동 유도 버튼
🛠 HANDS-ON

실습: 랜딩페이지 만들기

아래 프롬프트를 Cursor에 입력하세요. 주제는 자유롭게 바꿔도 OK!

"너는 웹 디자이너 겸 프론트엔드 개발자야. 우리 팀을 소개하는 랜딩페이지를 만들어줘. 구조: 1. 히어로: 팀명 + 한 줄 소개 + '더 알아보기' 버튼 2. 팀원 소개: 3명 카드형 (이름, 역할, 한마디) 3. 팀이 하는 일 3가지 아이콘 카드 4. 하단 CTA: '함께하기' 버튼 Tailwind CSS CDN 사용, 반응형 대응. 배경은 따뜻한 크림색, 둥근 카드 디자인. 하나의 HTML 파일로 만들어줘."
DEPLOY STEP 1

배포 준비: GitHub 계정 만들기

  1. github.com 접속
    회원가입 → 무료 계정 생성 (구글 로그인 가능)
  2. New Repository 클릭
    이름: my-landing-page / Public 선택 / Create
  3. 파일 업로드
    "Upload files" 클릭 → 만든 HTML 파일을 드래그 앤 드롭
  4. Commit changes 클릭
    파일이 GitHub에 저장됩니다!
💡 GitHub는 코드 저장소예요. 여기에 파일을 올려두면 Vercel이 자동으로 가져갑니다.
DEPLOY STEP 2

Vercel로 실제 배포하기

  1. vercel.com 접속 → GitHub로 로그인
    별도 회원가입 불필요. GitHub 계정으로 바로 연결
  2. "Add New Project" 클릭
    방금 만든 GitHub 저장소가 보입니다
  3. "Import" → "Deploy" 클릭
    기본 설정 그대로 → Deploy 버튼 누르면 끝!
  4. 🎉 배포 완료!
    https://my-landing-page.vercel.app 같은 URL이 생성됩니다
⏱ 전체 과정: 약 3분 · 이 URL을 카톡으로 공유하면 누구나 볼 수 있어요!

CONCEPT

정적 페이지 vs 웹 앱

📄 정적 페이지 (1~3주차)

  • HTML 파일 하나로 완성
  • 내용이 고정되어 있음
  • 데이터 저장 불가
  • 소개 페이지, 랜딩페이지
  • 새로고침해도 같은 내용

🚀 웹 앱 (4주차부터)

  • 여러 페이지, 여러 파일
  • 사용자 입력에 반응
  • 데이터 저장/불러오기 가능
  • 게시판, 폼, 대시보드, 채팅
  • 실시간으로 내용이 변함

FILE STRUCTURE

Next.js 프로젝트 구조

폴더가 곧 URL 경로가 됩니다. 외울 필요는 없어요!

📁 vibe-app/
📁 app/
📄 page.tsx ← 메인 페이지
📄 layout.tsx ← 공통 레이아웃
📁 posts/
📄 page.tsx ← /posts 페이지
📁 components/ ← 재사용 컴포넌트
📄 package.json

핵심 규칙

  • app/page.tsx → 메인 페이지 (/)
  • app/posts/page.tsx → /posts
  • 폴더를 만들면 = URL이 생긴다
  • AI에게 "새 페이지 추가해줘"라고 하면 알아서 폴더를 만들어줘요
SUPABASE 연동

데이터 연동 핵심 코드

직접 쓸 필요 없어요. AI가 만들어줍니다. 구조만 이해하세요.

// 데이터 가져오기 (Read) const { data } = await supabase .from('posts') .select('*') // 데이터 저장하기 (Create) await supabase .from('posts') .insert({ title: '첫 글', content: '안녕!' }) // 데이터 삭제하기 (Delete) await supabase .from('posts') .delete() .eq('id', 1)
TROUBLESHOOTING

자주 발생하는 문제 & 해결법

🔴 "Module not found"

패키지 설치가 안 된 것. AI에게 "이 에러 해결해줘" + 에러 메시지 전체를 붙여넣으세요.

🔴 데이터가 안 나와요

Supabase URL/Key를 확인하세요. 또는 RLS(보안 정책)을 비활성화해야 할 수도 있어요.

🔴 화면이 하얗게 나와요

터미널의 에러 메시지를 복사해서 AI에게 보내세요. 대부분 오타나 문법 문제입니다.

🔴 npm run dev가 안 돼요

Node.js가 설치되어 있는지 확인. 없으면 nodejs.org에서 설치 후 재시도.
