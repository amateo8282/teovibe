HOW TO DESIGN

자동화 프로젝트
설계하는 법

  1. 반복 업무 찾기
    "매주 엑셀에서 데이터 복사해서 리포트 만드는 게 귀찮아" 같은 것
  2. 입력과 출력 정의하기
    입력: Supabase 테이블 데이터 → 출력: 슬랙 메시지 + 요약 차트
  3. 트리거 정하기
    언제 실행? 매일 오전 9시? 버튼 클릭 시? 데이터 변경 시?
  4. AI에게 설명하기
    위 내용을 프롬프트로 정리해서 "이 자동화 만들어줘"

⚠️ SECURITY

API 키 보안 주의사항

API 키는 비밀번호와 같아요. 절대 코드에 직접 넣지 마세요!

❌ 이렇게 하면 안 돼요

  • 코드에 API 키를 직접 작성
  • GitHub에 키가 포함된 코드를 업로드
  • 슬랙이나 메일에 API 키를 공유

✅ 이렇게 하세요

  • .env.local 파일에 키를 저장
  • .gitignore에 .env 파일 추가
  • Vercel 환경변수에 키를 설정
💬 AI에게: "API 키를 환경변수로 관리하도록 설정해줘. .env.local 파일 사용하고 .gitignore도 추가해줘."
