DEFINITION

바이브 코딩이란?

AI 코딩 에이전트와 자연어(한국어)로 대화하며
코드를 생성하는 새로운 프로그래밍 방식.

💬 "로그인 페이지 만들어줘. 이메일과 비밀번호 입력 폼이 있고, 로그인 버튼을 누르면 대시보드로 이동해."

→ AI가 이 문장을 이해하고, 동작하는 코드를 생성합니다.
COMPARE

전통적 개발 vs 바이브 코딩

❌ 전통적 개발

  • 프로그래밍 언어 학습 (6개월~수년)
  • 문법, 알고리즘, 자료구조 암기
  • 에러 메시지와의 끝없는 싸움
  • 프레임워크별 학습 곡선
  • 코드 한 줄 한 줄 직접 타이핑

✅ 바이브 코딩

  • 한국어로 원하는 것을 설명
  • AI가 코드를 자동 생성
  • 에러도 AI가 진단하고 수정
  • 프레임워크 몰라도 사용 가능
  • 아이디어 → 결과물까지 수 시간

CURSOR IDE

Cursor IDE란?

VS Code를 기반으로 만들어진 AI 네이티브 코드 에디터입니다.
코드를 직접 작성하는 대신, AI와 대화하며 코드를 생성합니다.

✨ 핵심 기능

  • Cmd+K: 코드 생성/수정 지시
  • Cmd+L: AI와 채팅하며 개발
  • Tab: AI 자동완성 수락
  • Composer: 멀티파일 동시 작업

💡 왜 Cursor인가?

  • AI가 프로젝트 전체 맥락을 이해
  • 한국어 지시도 완벽 지원
  • 에러 자동 감지 & 수정 제안
  • 무료 플랜으로 충분히 학습 가능
🛠 HANDS-ON

실습: Cursor IDE 설치하기

  1. cursor.com 접속
    브라우저에서 cursor.com으로 이동합니다
  2. Download 클릭 → 설치
    운영체제에 맞는 버전이 자동 선택됩니다
  3. 계정 생성 (구글 로그인 가능)
    무료 플랜 선택 → 월 2,000회 AI 요청 제공
  4. 첫 프로젝트 폴더 생성
    바탕화면에 "vibe-coding" 폴더를 만들고 Cursor로 열기
  5. Cmd+L 눌러서 AI와 첫 대화!
    "안녕! 나는 코딩을 처음 배우는 학생이야" 입력해보기

AI 프롬프팅
마스터

AI에게 원하는 결과를 정확하게 얻어내는
프롬프트 설계의 기술을 배웁니다.

TODAY'S GOAL

오늘이 끝나면
여러분은

  • 좋은 프롬프트와 나쁜 프롬프트의 차이를 구분합니다
  • 역할 부여, 맥락 제공, 단계적 지시를 능숙하게 사용합니다
  • 실무에서 바로 쓸 수 있는 프롬프트 템플릿을 가져갑니다
  • AI와 "대화"하듯 개발하는 감각을 익힙니다
WHY PROMPTING?

같은 AI, 다른 결과

프롬프트 하나로 결과물의 품질이 10배 달라집니다.

😐 나쁜 프롬프트

  • "웹사이트 만들어줘"
  • "좋은 디자인으로 해줘"
  • "에러 고쳐줘"
  • "더 좋게 바꿔줘"

🤩 좋은 프롬프트

  • "CVC 투자심사 데이터를 입력/조회하는 웹앱을 만들어줘. 테이블 형태로."
  • "배경은 크림색(#F1EDE4), 폰트는 Pretendard, 카드형 레이아웃으로"
  • "콘솔에 'TypeError: Cannot read property' 에러가 나와. data가 null일 때 처리를 추가해줘"
  • "버튼 hover 시 그림자 효과 추가하고, 카드 간격을 24px로 통일해줘"
5 ELEMENTS

좋은 프롬프트의
5가지 요소

  1. 역할 (Role)
    "너는 시니어 프론트엔드 개발자야" — AI의 전문성 수준을 설정
  2. 맥락 (Context)
    "사내 교육 신청 시스템을 만들고 있어" — 배경 상황 설명
  3. 구체적 지시 (Instruction)
    "이메일, 이름, 부서를 입력받는 폼을 만들어줘" — 명확한 요구사항
  4. 제약 조건 (Constraints)
    "Tailwind CSS 사용, 모바일 반응형, 한국어로" — 기술적 조건
  5. 출력 형식 (Format)
    "하나의 HTML 파일로 만들어줘" — 결과물의 형태 지정
EXAMPLE

실전 프롬프트 예시

// 5가지 요소가 모두 포함된 프롬프트: "너는 시니어 웹 개발자야. (역할) 우리 팀에서 사내 교육 신청을 받으려고 해. (맥락) 교육 신청 폼을 만들어줘. 입력 항목: - 이름 - 부서 (드롭다운: 경영지원, 투자심사, 마케팅, 기술개발) - 이메일 - 참여 동기 (textarea) - 제출 버튼 (구체적 지시) 디자인은 깔끔하고 따뜻한 톤으로, 배경색 #F1EDE4, 버튼은 둥근 pill 형태. (제약 조건) 하나의 HTML 파일로 만들어줘. (출력 형식)"
CONVERSATIONAL DEV

대화하듯 개발하기

한 번에 완벽하게 만들 필요 없어요. 대화를 이어가세요.

나 "교육 신청 폼 만들어줘"
AI (폼 생성)
나 "부서 선택을 드롭다운으로 바꿔줘"
나 "제출하면 '신청 완료!' 알림 띄워줘"
나 "디자인을 좀 더 모던하게. 그림자 효과 추가"
나 "완벽해! 👍"
PRO TIPS

프롬프트 꿀팁 모음

📋

구체적으로 말하기

"좋게 만들어줘" 대신 "카드 간격 24px, 둥근 모서리 16px, 그림자 추가"처럼 수치로 말하세요.

🔄

점진적으로 발전시키기

한 번에 완벽한 프롬프트를 쓸 필요 없어요. 대화를 이어가며 개선하세요.

🎯

레퍼런스 제시하기

"토스 앱처럼", "노션 스타일로" 등 참고할 대상을 알려주면 품질이 올라갑니다.

🚫

에러가 나면 통째로 복사

에러 메시지를 그대로 복사해서 AI에게 보내세요. "이 에러 고쳐줘" + 에러 메시지 전체.
