1. 패키지 설치:
```bash
cd teovibe && pnpm add @tiptap/extension-text-align@^2.27.2 @tiptap/extension-color@^2.27.2 @tiptap/extension-highlight@^2.27.2 @tiptap/extension-text-style@^2.27.2
```
주의: @tiptap/extension-font-size는 설치하지 않는다 (v3.x 전용, v2.27.2 미존재).
주의: @tiptap/extension-text-style은 pnpm transitive dep으로만 있어 Vite가 직접 import 못함 — 반드시 직접 설치.

2. `teovibe/app/frontend/editor/font_size_extension.js` 신규 파일 생성:
- `Extension.create()` 패턴으로 커스텀 FontSize extension 구현
- name: "fontSize"
- options.types: ["textStyle"] (TextStyle mark 위에서 동작)
- addGlobalAttributes(): textStyle 타입에 fontSize attribute 추가
  - parseHTML: `element.style.fontSize.replace(/['"]+/g, "") || null`
  - renderHTML: `{ style: \`font-size: ${attributes.fontSize}\` }` (값 없으면 빈 객체)
- addCommands(): setFontSize(fontSize) — chain().setMark("textStyle", { fontSize }), unsetFontSize() — chain().setMark("textStyle", { fontSize: null }).removeEmptyTextStyle()
- 16-RESEARCH.md의 "Pattern 4: 커스텀 FontSize extension" 코드를 그대로 사용

3. `admin_rhino_editor.js` import 섹션에 추가:
```javascript
import TextAlign from "@tiptap/extension-text-align"
import TextStyle from "@tiptap/extension-text-style"
import Color from "@tiptap/extension-color"
import Highlight from "@tiptap/extension-highlight"
import { FontSize } from "../editor/font_size_extension.js"
```

4. connectedCallback()에서 extension 등록 추가 (기존 Underline 아래에):
```javascript
this.addExtensions(TextAlign.configure({ types: ["heading", "paragraph"] }))
this.addExtensions(TextStyle, Color, FontSize)
this.addExtensions(Highlight.configure({ multicolor: true }))
```
순서 중요: TextStyle이 Color/FontSize보다 먼저 등록되어야 한다.
TextAlign의 types에 heading과 paragraph 모두 지정 필수 (생략 시 어떤 노드에도 정렬 미적용).
Highlight는 multicolor: true 필수 (기본값 false는 노란색 고정).
