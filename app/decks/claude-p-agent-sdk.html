CONCEPT 01

claude -p 란?

-p는 --print의 축약형.
터미널 대화형 UI 없이 프롬프트를 실행하고 stdout으로 결과를 출력.

# 가장 단순한 형태 claude -p "이 프로젝트의 구조를 요약해줘" # 도구 허용 + JSON 출력 claude -p "테스트를 실행하고 실패 원인을 찾아 요약해줘" \ --allowedTools "Read,Glob,Grep,Bash" \ --output-format json
⚡ 에이전틱 실행 — 단순 LLM 답변이 아니다. 파일 탐색→도구 호출→결과 확인→반복의 에이전트 루프가 돈다.
COMPARE

단순 LLM 호출 vs claude -p

💬 단순 LLM API 호출

  • 프롬프트 입력
  • → 텍스트 답변 반환
  • 파일 시스템 접근 없음
  • 명령 실행 없음
  • 한 번의 요청·응답으로 끝

🤖 claude -p (에이전틱 실행)

  • 목표 입력
  • → 필요한 파일 탐색
  • → 도구 호출·명령 실행
  • → 결과 확인·필요 시 반복
  • → 최종 결과 출력
⚠️ 그래서 권한을 좁게 설계해야 한다. 파일 수정·삭제 권한은 승인 흐름이 있을 때만 부여.
PRACTICE 01

크론잡에서 가장 단순한 구조

#!/bin/zsh set -euo pipefail # 프로젝트 디렉토리로 이동 cd "$HOME/apps/cvc-laps" # claude -p 호출 — 읽기 전용 점검 claude -p \ --allowedTools "Read,Glob,Grep,Bash" \ --output-format json \ "프로젝트 빌드를 실행하고 오류를 점검해줘. 파일은 수정하지 말고 문제점과 권장 조치만 정리해줘." \ | jq -r '.result'
💡 처음엔 점검 전용으로 시작. 파일 수정 권한(Edit, Write)은 승인 흐름이 생긴 다음에 추가.
SECURITY

자동화 권한 — 좁게 설계한다

✅ 정기 점검용 (매일 자동)

  • Read
  • Glob
  • Grep
  • Bash (제한적)
→ 보고서·요약만 출력
파일 변경 없음

⚡ 승인 후 수정용 (온디맨드)

  • Read · Glob · Grep
  • Edit
  • Write
  • Bash
→ 텔레그램 승인 후 실행
변경 파일 목록 로그 기록
⚠️ 매일 자동 실행 잡에 Edit·Write를 주면 예상치 못한 파일 변경이 생길 수 있다. 분리 운영 필수.
OUTPUT

JSON 출력으로 후속 자동화에 연결

# 기본 JSON 응답 claude -p "프로젝트 요약해줘" --output-format json # jq로 텍스트만 추출 claude -p "프로젝트 요약해줘" --output-format json | jq -r '.result' # JSON Schema 기반 구조화 출력 claude -p "오류를 심각도별로 분류해줘" \ --output-format json \ --json-schema '{"type":"object","properties":{"issues":{"type":"array","items":{"type":"object","properties":{"severity":{"type":"string"},"summary":{"type":"string"}}}}},"required":["issues"]}'
💡 구조화 출력 활용처: 노션 DB 업데이트 · 텔레그램 심각도별 알림 · 승인 필요 항목만 큐 등록
CONCEPT 02

Agent SDK란?

Claude Code의 도구, 에이전트 루프, 컨텍스트 관리 기능을 Python 또는 TypeScript 코드에서 직접 제어하는 라이브러리.

SDK는 컨테이너가 아니다.
Docker 컨테이너 안에 SDK 앱을 넣을 수는 있지만, SDK 자체는 제작 키트다.

COMPARE

claude -p vs Agent SDK

구분 claude -p Agent SDK
성격 CLI 인터페이스 Python·TypeScript 라이브러리
비유 한 줄 명령으로 전문가 호출 업무 매뉴얼·승인 절차 내장 팀 제작
적합한 상황 단발성 작업, 간단한 크론잡, CI 복잡한 분기·재시도·승인·서브에이전트
장점 빠르고 단순, 셸 스크립트에 바로 세밀한 제어, 확장성
시작 비용 낮음 높음 (프로그램 직접 작성)
💡 claude -p로 가치를 검증하고, 복잡도가 올라갈 때 SDK로 확장하는 것이 효율적.
CODE

Agent SDK 코드 예시 (Python)

import asyncio from claude_agent_sdk import query, ClaudeAgentOptions async def main(): async for message in query( prompt="프로젝트를 검사하고 테스트 실패 원인을 요약해줘", options=ClaudeAgentOptions( allowed_tools=["Read", "Glob", "Grep", "Bash"] ), ): if hasattr(message, "result"): print(message.result) asyncio.run(main())
⚡ 핵심 차이: 문자열 하나가 아니라 메시지 이벤트와 실행 흐름을 코드 내부에서 다룬다.
AUTH

인증 방식 — 뭘 써야 하나?

방식환경 변수과금적합한 상황
구독 OAuth 토큰 CLAUDE_CODE_OAUTH_TOKEN Agent SDK 크레딧 차감 개인 스크립트, 개인 크론잡, CI 파이프라인
Claude Platform API 키 ANTHROPIC_API_KEY 사용량 기반 API 과금 팀 공유 자동화, 고객 대상 서비스, 상시 운영
⚠️ 주의 3가지
1. ANTHROPIC_API_KEY가 설정되면 API 키가 우선 적용된다.
2. --bare 모드는 OAuth 토큰을 읽지 않는다. API 키 필요.
3. 고객용 SaaS에 본인 구독 토큰을 연결하려면 Anthropic 사전 승인이 필요하다.

ROADMAP

Hermes 환경 권장 도입 순서

    고객 요청·팀 공유 자동화 → pay-as-you-go
