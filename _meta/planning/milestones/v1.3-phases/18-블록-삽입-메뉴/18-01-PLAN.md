admin_rhino_editor.js에 다음 4개 메서드를 추가하고 기존 startEditor/disconnectedCallback을 업데이트한다.

1. `_isEmptyParagraph()` — TipTap FloatingMenu 소스에서 검증된 빈 단락 감지 알고리즘:
   - `view.hasFocus()` + `editor.isEditable` + `selection.empty`
   - `$anchor.depth === 1` (최상위 블록만 — 표 셀/리스트 내부 제외)
   - `$anchor.parent.isTextblock` + `!$anchor.parent.type.spec.code`
   - `$anchor.parent.childCount === 0` + `!$anchor.parent.textContent`
   - 8개 조건 모두 AND로 결합, 하나라도 실패하면 false 반환

2. `_initFloatingMenu()` — Light DOM 플로팅 메뉴 생성 (Phase 17 _initTableContextMenu 패턴 동일):
   - 외부 div (position:absolute, z-index:50, display:none)
   - + 버튼 (24x24px 원형, border:1px solid #d1d5db, type="button" 필수)
   - 서브 메뉴 패널 (기본 숨김, left:30px, 4개 항목: 구분선/인용구/코드블록/표)
   - 모든 서브 메뉴 버튼에 type="button" 필수 (form submit 방지)
   - hover 시 #f3f4f6 배경
   - + 버튼 click → panel toggle, panel click → _handleFloatingMenuClick
   - 컨테이너: `this.closest("form") || document.body`

3. `_updateFloatingMenu()` — 표시/위치 업데이트:
   - null 가드: `if (!this._floatingMenu) return`
   - `_isEmptyParagraph()` false → 메뉴+패널 둘 다 display:none
   - true → `editor.view.coordsAtPos(from)`으로 뷰포트 좌표 계산
   - 버튼 크기 24px 기준, 커서 행 수직 중앙에 배치
   - 에디터 DOM의 `getBoundingClientRect().left` 기준 왼쪽 여백에 배치 (left - 24 - 8)
   - `Math.max(0, left)`로 음수 방지

4. `_handleFloatingMenuClick(e)` — 삽입 커맨드 실행:
   - `data-action` 속성으로 항목 식별
   - horizontal-rule → `chain.setHorizontalRule().run()`
   - blockquote → `chain.toggleBlockquote().run()`
   - code-block → `chain.toggleCodeBlock().run()`
   - table → `chain.insertTable({ rows: 3, cols: 3, withHeaderRow: true }).run()`
   - 실행 전 메뉴+패널 숨김, 실행 후 focus 유지

5. `startEditor()` 업데이트 — 기존 Phase 17 코드 이후에 추가:
   - `this._initFloatingMenu()`
   - `editor.on("selectionUpdate", () => this._updateFloatingMenu())`
   - `editor.on("update", () => this._updateFloatingMenu())` — 텍스트 입력 시 즉시 감지
   - `editor.on("blur", ...)` — `_floatingMenu` + `_floatingPanel` 둘 다 display:none

6. `disconnectedCallback()` 업데이트 — 기존 _tableMenu 정리 이후에 추가:
   - `this._floatingMenu?.remove()`
   - `this._floatingMenu = null`
   - `this._floatingPanel = null`

주의사항:
- @tiptap/extension-floating-menu 설치 시도 금지 (tippy.js 의존성, Shadow DOM 충돌)
- Shadow DOM 내부에 메뉴 렌더링 금지 (position:absolute 범위 제한됨)
- 기존 Phase 15~17 코드 절대 손대지 않기 — 추가만 할 것
- 파일 상단 주석에 Phase 18 설명 추가
