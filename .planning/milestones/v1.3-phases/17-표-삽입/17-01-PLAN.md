admin_rhino_editor.js를 수정하여 표 기능 전체를 구현한다.

1. **import 추가** (파일 상단):
```javascript
import Table from "@tiptap/extension-table"
import TableRow from "@tiptap/extension-table-row"
import TableCell from "@tiptap/extension-table-cell"
import TableHeader from "@tiptap/extension-table-header"
```

2. **connectedCallback에 Table extension 등록** (기존 Highlight 아래에):
```javascript
// Phase 17: Table extension 4종
this.addExtensions(
  Table.configure({ resizable: false }),
  TableRow,
  TableCell,
  TableHeader
)
```
- `resizable: false` 필수 — true는 drag handle 이벤트가 rhino-editor 포인터 이벤트와 충돌
- 4개 전부 등록 필수 — 누락 시 insertTable 커맨드가 스키마 검증 실패

3. **startEditor() override 추가** — editor 생성 후 컨텍스트 메뉴 초기화:
```javascript
async startEditor() {
  await super.startEditor()
  this._initTableContextMenu()
}
```
주의: connectedCallback이 아닌 startEditor에서 초기화해야 함. rhino-editor의 startEditor()가 async이므로 connectedCallback 시점에는 this.editor가 null.

4. **renderInsertTableButton() 메서드 추가**:
- `this.editor?.can().insertTable()`로 disabled 상태 체크 (표 안에서 중첩 삽입 방지)
- 클릭 시 `this.editor?.chain().focus().insertTable({ rows: 3, cols: 3, withHeaderRow: true }).run()`
- HTML entity `&#8862;` (표 아이콘) 사용
- 기존 버튼 패턴과 동일한 class/aria 속성

5. **renderToolbarEnd() 수정** — 마지막에 `${this.renderInsertTableButton()}` 추가

6. **_initTableContextMenu() 메서드 구현**:
- Light DOM에 `<div>` 컨텍스트 메뉴 생성 (shadow DOM 외부 — position:absolute가 shadow DOM 경계에 갇히지 않도록)
- `this.closest("form") || document.body`에 appendChild
- 스타일: `position:absolute; z-index:100; display:none; background:white; border:1px solid #e5e7eb; border-radius:6px; box-shadow:0 2px 8px rgba(0,0,0,0.15); padding:4px;`
- 버튼 7개: 위에 행 추가, 아래 행 추가, 행 삭제, 왼쪽 열 추가, 오른쪽 열 추가, 열 삭제, 표 삭제
- 각 버튼에 `data-action` 속성으로 action 식별
- 버튼 스타일: `display:block; width:100%; text-align:left; padding:4px 12px; border:none; background:none; cursor:pointer; font-size:13px; border-radius:4px;`
- 버튼 hover: `onmouseenter` style.background="#f3f4f6", `onmouseleave` style.background="none"
- 메뉴 click 이벤트 위임: `_handleTableMenuClick(e)` 호출

7. **editor 이벤트 리스너 등록** (startEditor 내, _initTableContextMenu 호출 후):
- `this.editor?.on("selectionUpdate", () => this._updateTableMenu())`
- `this.editor?.on("blur", () => { if (this._tableMenu) this._tableMenu.style.display = "none" })`

8. **_updateTableMenu() 메서드 구현**:
- `this.editor.isActive("table")`로 표 안 여부 확인
- `this.editor.state.selection.empty`로 텍스트 선택 여부 확인
- 핵심 로직: `!isInTable || !empty`이면 메뉴 숨김 (텍스트 선택 시 기존 버블 메뉴에 양보)
- 위치 계산: `this.editor.view.coordsAtPos(from)` + `window.scrollY`/`window.scrollX`
- 메뉴가 뷰포트 상단을 넘으면 커서 아래로 fallback: `coords.top + window.scrollY + 20`

9. **_handleTableMenuClick(e) 메서드 구현**:
- `e.target.closest("[data-action]")?.getAttribute("data-action")`으로 action 추출
- `e.preventDefault()` 호출 (폼 submit 방지)
- action별 커맨드 매핑:
  - "add-row-before": `this.editor.chain().focus().addRowBefore().run()`
  - "add-row-after": `this.editor.chain().focus().addRowAfter().run()`
  - "delete-row": `this.editor.chain().focus().deleteRow().run()`
  - "add-col-before": `this.editor.chain().focus().addColumnBefore().run()`
  - "add-col-after": `this.editor.chain().focus().addColumnAfter().run()`
  - "delete-col": `this.editor.chain().focus().deleteColumn().run()`
  - "delete-table": `this.editor.chain().focus().deleteTable().run()`

10. **disconnectedCallback() 추가** — 메모리 누수 방지:
```javascript
disconnectedCallback() {
  super.disconnectedCallback()
  this._tableMenu?.remove()
  this._tableMenu = null
}
```

피해야 할 것:
- 기존 renderToolbar()를 건드리지 말 것 — 기존 Bold/Italic/Strike 등 버튼은 그대로 유지
- Table 4개 중 하나라도 빠뜨리지 말 것 — 누락 시 스키마 오류
- _initTableContextMenu에서 Lit html 태그를 사용하지 말 것 — Light DOM은 일반 DOM API 사용
- editor.on 리스너를 connectedCallback에 넣지 말 것 — this.editor가 null
