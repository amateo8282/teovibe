    - Test 3: 구 named routes (blogs_path, tutorials_path 등) 가 sitemap에 포함되지 않는다
    - Test 4: 신규 카테고리를 DB에 추가하면 sitemap 재생성 시 자동 반영된다
  </behavior>
  <action>
    1. `config/sitemap.rb`의 카테고리 인덱스 섹션 교체:
       - 기존 `case slug when "blog" then blogs_path ...` 하드코딩 삭제
       - `Category.for_posts.ordered.each { |cat| add category_posts_path(category_slug: cat.slug), changefreq: "daily", priority: 0.8 }` 동적 루프로 교체
    2. 게시글 섹션 교체:
       - 기존 `case slug when "blog" then blog_path(post) ...` 하드코딩 삭제
       - 현재 라우트 확인: `resources :posts, param: :slug` → `post_path(post)` 가 `/posts/:slug` 생성
       - `Post.published.find_each { |post| add post_path(post), lastmod: post.updated_at, changefreq: "weekly", priority: 0.8 }` 로 교체
       - 카테고리 없는 게시글도 slug가 있으면 포함 (카테고리 의존성 제거)
    3. 정적 페이지, 스킬팩 섹션은 변경하지 않음 (기존 코드 보존)
    4. 테스트: `SitemapGenerator::Sitemap.create` 실행 후 생성된 XML에서 URL 패턴 확인.
       sitemap_generator는 `public/sitemaps/` 에 파일 생성하므로 테스트 후 정리 필요.
       또는 SitemapGenerator::Sitemap.instance_variable로 URL 목록 접근 가능한지 확인.
